## Sobre

Este projeto é uma Landing Page de página única desenvolvida para apresentar informações essenciais de maneira simples e organizada. A proposta é oferecer uma estrutura clara e visual atraente, ideal para destacar produtos, serviços ou conteúdo profissional.

## Como executar

Copie e cole o link abaixo na barra de pesquisa do seu navegador:

```
https://fabio-oliveira-martins.github.io/huddle-landing-page-with-single-introductory-section-master/
```
